# 🌸 Bunny Analytics Hub

*Математика · Статистика · Финансы — в одном уютном приложении* 💜

Интерактивное веб-приложение на **R + Shiny**.
Три функциональных блока по **10 задач каждый**.
Поддерживает ввод пользовательских данных и визуализацию результатов.

---

## 🚀 Как запустить

### Способ 1 — одна команда в RStudio

Установите пакеты один раз:

`install.packages(c("shiny", "shinydashboard", "ggplot2", "DT"))`

Затем запустите приложение:

`shiny::runGitHub("FinMathApp", "MargoRita67")`

### Способ 2 — скачать и открыть

1. Нажмите **Code → Download ZIP**.
2. Распакуйте архив.
3. Откройте файл `FinMathApp.Rproj` в RStudio.
4. Нажмите кнопку **Run App**.
